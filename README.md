# Godot-Trigger
![Godot Trigger Logo](https://github.com/Clipper-YT/Godot-Trigger/blob/main/sprites/godot_trigger_logo.png?raw=true)
A 2D JRPG framework for Godot 4.7.
This attempts to bring in almost every feature one would want from an SNES-era JRPG, such as the option to use either Turn-Based or Active Time Battles, saving/loading, a magic system, spells, multiple characters, an overworld, full UI, and more!
